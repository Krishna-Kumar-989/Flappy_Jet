
Flappy Jet 🛩️

**Flappy Jet** is a lightweight, fast-paced arcade game inspired by the classic **Flappy Bird**. Built with **Unity** and **C#**, and compiled for **Windows**, it's designed for instant gameplay — no menus, no waiting.

> ⚠️ **Note:** This repository contains only the **compiled game files**. The Unity project and source code are **not included**.

---

🎮 Gameplay

* **Click/tap** to keep your jet airborne.
* **Avoid obstacles** as long as you can.
* **Instant restart** after crashing — no menus or delays.

---

🖥️ How to Play

You have two options to run the game on Windows:

✅ Option 1: Play Directly from Repository

1. Clone or download this repository:

   ```bash
   git clone https://github.com/Krishna-Kumar-989/Flappy-Plane-game.git
   ```
2. Open the `/Build` folder.
3. Double-click `FlappyJet.exe` to start the game.

✅ Option 2: Install via Setup File

1. Navigate to:

   ```
   /Flappy Install/FlappyInstall.exe
   ```
2. Run the installer (built with **Inno Setup**).
3. Launch **Flappy Jet** from your Start menu or desktop shortcut.

🐦 Inspiration

**Flappy Jet** is a inspired by the iconic **Flappy Bird**, with the same addictive gameplay loop and minimalist design — simple to play, tough to master.
